# Vel-Vet Vows — Event Management Website

[![Live Demo](https://img.shields.io/badge/Live%20Demo-View%20Site-brightgreen?style=for-the-badge)](https://event-management-website-mocha.vercel.app)

A responsive multi-page website for **Vel-Vet Vows**, an event planning and management company. The site presents the company's services, past event galleries, client testimonials, and a booking system, built with a strong focus on visual storytelling, smooth animations, and a clean, modern user experience.

## Preview

![Vel-Vet Vows Homepage](homepage.png)

## Features

- Multi-page architecture covering Services & Pricing, Gallery, About Us, Feedback, Booking Form, and Contact
- Animated hero section introducing the brand and its mission
- Scroll-triggered fade and reveal animations powered by AOS (Animate On Scroll)
- Image-driven "About Us" section highlighting the company's story and values
- Auto-rotating testimonials carousel showcasing real client feedback
- Newsletter subscription form with client-side email validation
- Dedicated event booking form for capturing client requests
- Responsive navigation bar that adapts to desktop, tablet, and mobile devices
- Footer with contact details, quick links, and social media integration

- **HTML5** — Semantic page structure across the homepage and sub-pages
- **CSS3** — Custom styling layered on top of Bootstrap for a distinct brand look
- **JavaScript** — Client-side interactivity and form handling
- **Bootstrap 5** — Responsive grid system, navigation, and carousel components
- **Font Awesome** — Icon set used across contact info, social links, and UI elements
- **AOS (Animate On Scroll)** — Scroll-based reveal and fade animations throughout the site

## Project Structure

```
│   ├── service.html          # Services & pricing
│   ├── gallery.html          # Event gallery
│   ├── aboutus.html          # Full about us page
│   ├── feedback.html         # Client feedback / testimonials page
│   ├── booking_form.html     # Event booking form
│   └── contact.html          # Contact page
├── other_page_css/          # Stylesheets specific to individual sub-pages
├── Pictures/                 # Homepage imagery (hero, about section, etc.)
├── gallery_images/           # Image assets used in the gallery page
└── .vscode/                  # Editor configuration
```

## Getting Started

Clone the repository:

```bash
git clone https://github.com/AbdulRehman2345/Event-Management-Website.git
```

Open the project folder and launch `index.html` in your browser. This is a static frontend project — no build tools, package installation, or server setup required.

## Purpose

This project was built to demonstrate a complete, production-style business website for a service-based company, covering brand storytelling, service presentation, social proof through testimonials, and lead capture through a booking form — all wrapped in a polished, animated, and fully responsive frontend.
